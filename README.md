# 🎓 Mestrado em Computação Aplicada

Repositório central com todos os estudos, notas de aula, exercícios e projetos desenvolvidos durante o programa de **Mestrado em Computação Aplicada** da UTFPR.

Este é um espaço de aprendizado contínuo focado em **Machine Learning, Data Science e Computação Aplicada**.

---

## 📚 Disciplinas

### Machine Learning
**Ministrada por:** [Prof. Francisco de Assis Boldt](https://fboldt.github.io/)

Uma jornada prática e teórica por Machine Learning, desde regressão linear até clustering avançado. Cada aula inclui:
- 📖 **Explicações pedagógicas** detalhadas em Markdown
- 🔧 **Implementação do zero** para entender a matemática
- 🏢 **Uso de bibliotecas profissionais** (sklearn, pandas, numpy)
- 📊 **Visualizações interativas** para intuição geométrica
- ✅ **Projetos práticos** como Titanic dataset

**Tópicos Cobertos:**
- ✅ Regressão (Linear, Normal Equation, Comparações)
- ✅ Classificação (Linear Threshold, KNN, Árvores, Ensembles)
- ✅ Validação (Cross-Validation, Grid Search, Pipelines)
- ✅ Clustering (K-Means, DBSCAN, Semi-Supervised)

## 🚀 Como Começar

### Opção 1: Localmente
```bash
# Clone o repositório
git clone https://github.com/Paulo83-dev/mestrado-computacao-aplicada.git
cd mestrado-computacao-aplicada

# Instale as dependências
pip install scikit-learn pandas numpy matplotlib seaborn jupyter

# Inicie o Jupyter
jupyter notebook
```

Cada notebook possui um botão **"Open in Colab"** no topo para execução direto na nuvem, sem necessidade de instalação.

## 💡 Filosofia do Aprendizado

> **"O melhor jeito de aprender Machine Learning é entender a matemática através da prática, não apenas memorizar APIs."**

Cada aula segue este padrão:
1. **Entender o problema** através de dados reais
2. **Implementar do zero** para ver a matemática em ação
3. **Usar bibliotecas profissionais** para escala
4. **Visualizar** resultados para intuição
5. **Avaliar rigorosamente** com métricas apropriadas
